# 🧟 ZOMBIE // CHAT

> TALK. SHARE. SURVIVE.

A lightweight local-network chat system built with Flask.

Zombie Chat lets people connected to the same local network send messages,
share images, and capture photos directly from their camera.

## ✨ Features

- 💬 Local network chat
- 🧟 Persistent user handles
- 📷 Camera capture
- 🖼️ Image sharing
- 📱 Mobile-friendly UI
- 🔄 Automatic message refresh
- ⚡ Lightweight Flask backend
- 🎨 Retro hacker-style interface

## 🛠️ Tech Stack

- Python
- Flask
- Werkzeug
- HTML
- CSS
- JavaScript
- Browser Camera API
- LocalStorage
